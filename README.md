# Serg — «Акулёнок и зайчонок»

Вертикальный клип **9:16, ровно 5 секунд**, мягкая округлая 3D-анимация (плюш + глянец),
тёплый золотистый свет, пастельная лесная поляна и радужное облако.

**Файл:** [`out/shark_bunny_dance_5s_9x16.mp4`](out/shark_bunny_dance_5s_9x16.mp4)

| параметр | значение |
|---|---|
| длительность | 5.000 с (150 кадров) |
| разрешение | 1080 × 1920 (9:16) |
| fps | 30 |
| кодек | H.264 High, yuv420p, CRF 17, `+faststart` |
| звук | тишина (AAC 48 кГц, без музыки и реплик) |
| текст / лого / водяные знаки | нет |
| затемнение в конце / заставка | нет |

## Раскадровка

* **0.0–3.0 с** — короткий радостный танец: зайчонок мягко подпрыгивает (squash & stretch),
  акулёнок «плывёт» — покачивается и машет плавниками; уши и шарфик качаются с запаздыванием,
  камера очень мягко покачивается в ритме (1.2 Гц), без тряски и склеек.
* **3.0–4.0 с** — оба смотрят в камеру и делают один медленный дружелюбный взмах:
  зайчонок поднимает и покачивает лапкой, акулёнок — плавниками.
* **4.0–5.0 с** — расслабленные тёплые улыбки, камера чуть отъезжает и фиксируется,
  мягкое тёплое свечение нарастает; поза удерживается до последнего кадра.

## Как это сделано

Полностью детерминированный рендер без генерации видео-моделью: две статичные 3D-картинки
(мастер-поза + пустая поляна) превращаются в 2.5D-«кукольный» риг.

```
pip install pillow numpy opencv-python-headless imageio-ffmpeg

python tools/1_prepare.py     # маска персонажей + выравненный фон -> assets/derived/
python tools/2_render.py      # 150 кадров -> out/shark_bunny_dance_5s_9x16.mp4
python tools/2_render.py --debug   # превью-кадры в build/
```

* `tools/1_prepare.py` — ECC-выравнивание фона по мастер-позе и матирование персонажей
  (watershed: синий акулёнок / жёлтый зайчонок), мягкая альфа.
* `tools/2_render.py` — риг: перенос/масштаб/наклон тела (прыжок, приседание, покачивание)
  плюс локальные вращения вокруг «суставов» для ушей, шарфика, лапки и плавников;
  контактные тени на земле; камера с плавным покачиванием, отъездом и фиксацией;
  пастельный грейд, мягкий bloom и тёплое свечение в последнюю секунду.

## Исходники

* `assets/keyframes/k4.png` — мастер-поза (оба персонажа, взгляд в камеру).
* `assets/plate.png` — та же поляна без персонажей.
* `assets/derived/` — выравненный фон и готовые RGBA-спрайты (генерируются стадией 1).

Остальные сгенерированные позы (`k0…k3, k5…k7`) в репозиторий не входят — в финальном
риге используется одна мастер-поза, вся пластика получается из неё.
